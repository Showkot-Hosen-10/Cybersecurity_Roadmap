## Wireless & Networking Rooms (TryHackMe)

1. [Intro to LAN](https://tryhackme.com/room/introtolan)  
   Foundational room on local area networks, IP addressing, subnetting, and how devices communicate at a basic level. [web:69]

2. [Introductory Networking](https://tryhackme.com/room/introtonetworking)  
   High-level introduction to core networking concepts, OSI model, and common protocols useful before diving into more complex labs. [web:51]

3. [Network Traffic Basics](https://tryhackme.com/room/networktrafficbasics)  
   Explains how to capture and analyse network traffic, introducing PCAPs and common tools used in network forensics and monitoring. [web:72]

4. [Network Security Essentials](https://tryhackme.com/room/networksecurityessentials)  
   Covers network perimeters, firewalls, and key threats, with practical log review to spot suspicious activity on networks. [web:71]

5. [Nmap Live Host Discovery](https://tryhackme.com/room/nmap01)  
   Focused room on discovering live hosts using Nmap (ARP, ICMP, TCP/UDP ping scans) as a basis for later network enumeration. [web:69]

6. [Network Services](https://tryhackme.com/room/networkservices)  
   Teaches enumeration and exploitation of common network services (e.g., FTP, SSH, SMB) and their misconfigurations. [web:20]

7. [Network Services 2](https://tryhackme.com/room/networkservices2)  
   Sequel room introducing more complex and less common network services and how to identify and exploit their weaknesses. [web:70]

8. [Wifi Hacking 101](https://tryhackme.com/room/wifihacking101)  
   Practical wireless security room covering WPA/WPA2 attacks, handshake capture, and cracking against Wi-Fi networks. [web:74]
